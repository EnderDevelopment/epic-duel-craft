# Minecraft Modpack: Medieval Magic

A Minecraft modpack for two players, featuring a medieval fantasy theme with castles, dragons, magic, ruins, dungeons, and dimensions. The pack includes a variety of mods to enhance the gameplay experience, with a focus on performance and stability. It is designed to be compatible with hosting services that use tokens, and optimized for the MacBook Pro 2018 Intel UHD 630, ensuring smooth and stable gameplay with lightweight shaders.

## Install

### Client Side

1. Install Minecraft 1.20.1.
2. Install Forge 1.20.1.
3. Download the modpack from the provided link.
4. Extract the modpack into your Minecraft mods folder.
5. Launch Minecraft and select the modpack.

### Server Side

1. Install Minecraft 1.20.1 server.
2. Install Forge 1.20.1 server.
3. Download the server modpack from the provided link.
4. Extract the server modpack into your Minecraft server mods folder.
5. Start the server.

## Use

1. Launch Minecraft and select the Medieval Magic modpack.
2. Create a new world or join an existing one.
3. Explore the medieval fantasy world, engage in challenging battles, and discover hidden treasures.
4. Use the provided commands to enhance your gameplay experience.
